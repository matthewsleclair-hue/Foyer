Foyer Drop

Welcome back

Sign in to send things to your TV.

Send a note

It appears on the TV's home screen right away.

Draw something

Your drawing shows on the TV's home screen. The newest one wins.

Send photos

They join the TV's screensaver when it is set to "Photo drop".

Send games

Your own game files go to the TV's Games, ready to play: Game Boy Advance, Game Boy, NES, SNES, N64 and Mega Drive.

Only send games you own. GameCube and Wii discs are too big to send this way: on a PC, copy them into the Games folder instead.

Open on TV

Tap an app and the TV opens it. Foyer has to be on screen.

Remote

Works fully inside Foyer. In other apps, Back, Home and the play buttons always work; arrows, OK and typing work in many apps but not all (Netflix and YouTube draw their own screens).

Link a TV

On the TV: Foyer Settings → Home screen → Foyer Drop → Link this TV. Then type the code it shows.

Household

They choose "Create an account" on this page and enter it. Each account has its own TVs, notes and photos.

GitHub builds Foyer for TVs and PCs whenever there's a new version. With a token, this server fetches each one by itself (every 10 minutes) and your TVs and PCs update from here. Make one at github.com → Settings → Developer settings → Fine-grained tokens: only the Foyer repository, Contents: Read-only.

Search on the TV shows which of your apps have a show or movie (Netflix, Crave, Disney+, Prime Video…). That list comes from TMDB, which is free: make an account at themoviedb.org, then Settings → API → create a key (personal use). Paste it here once; your TVs never need it.
